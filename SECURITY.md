# Security Policy

## Supported Versions

Only the latest release on the primary development branch is currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Trilingo, please report it privately. **Do not disclose security vulnerabilities publicly through GitHub issues or discussions.**

### Contact
Please send your vulnerability report directly to:
**28justinreyes@gmail.com**

Please include the following details where possible:
- Type of issue (e.g. path traversal, SQL injection, arbitrary code execution, CSRF)
- Full paths of source file(s) related to the manifestation of the issue
- Step-by-step instructions or proof-of-concept to reproduce the issue
- Affected components (backend API, frontend client, or backup/restore archive parser)
- Any proposed mitigations or fixes

### Response Timeline
- We will acknowledge receipt of your report within 48 hours.
- We will provide an assessment of the vulnerability and coordinate a timeline for patch release and advisory disclosure.
